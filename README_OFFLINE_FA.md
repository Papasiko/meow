# راهنمای نصب آفلاین سامانه ارزیابی — Windows 10 Pro / Python 3.12 x64

## نکته مهم: ZIP آماده‌سازی اولیه، هنوز حاوی بسته‌های کتابخانه نیست

سرور مقصد اینترنت ندارد. بنابراین باید یک بار روی رایانه ویندوزی دیگری که اینترنت دارد، فایل‌های wheel مربوط به Python 3.12 و Windows x64 دریافت و به ZIP نهایی اضافه شوند. این کار با `prepare_offline_packages.bat` خودکار می‌شود. **تا وقتی پیام SUCCESS و ساخت `OrgEvaluation_Windows10_Python312_OfflineReady.zip` را ندیده‌اید، بسته برای نصب آفلاین آماده نیست.**

## بخش A — آماده کردن ZIP نهایی روی رایانه‌ای که اینترنت دارد

1. ZIP اولیه پروژه را در یک پوشه محلی استخراج کنید.
2. داخل پوشه `org_evaluation_v2`، روی `prepare_offline_packages.bat` دوبار کلیک کنید. منطق آماده‌سازی اکنون در فایل PowerShell `prepare_offline_packages.ps1` اجرا می‌شود تا خطاهای تفسیر CMD کمتر شود. اگر پنجره بسته شد، PowerShell را باز کنید و این دستور را در همان پوشه اجرا کنید: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\prepare_offline_packages.ps1`.
3. این مرحله از اینترنت عمومی برای دریافت کتابخانه‌ها استفاده می‌کند و فایل‌های سازگار با Windows x64 / CPython 3.12 را در پوشه `wheelhouse` می‌ریزد. لازم نیست روی آن رایانه حتماً Python 3.12 نصب باشد؛ Python و pip در هر نسخه‌ای که از گزینه‌های دانلود هدف پشتیبانی کند کافی است.
4. اگر پیام `SUCCESS` دیدید، فایل `OrgEvaluation_Windows10_Python312_OfflineReady.zip` در پوشه والد پروژه ساخته می‌شود. این ZIP نهایی را روی فلش کپی کنید. اگر خطا دیدید، فایل هنوز کامل نیست.

## بخش B — نصب روی سرور بدون اینترنت

1. ZIP نهایی را از فلش به یک مسیر محلی سرور کپی کنید و استخراج کنید؛ مثلاً `C:\OrgEvaluation\`. برنامه را مستقیماً از فلش اجرا نکنید.
2. وارد `org_evaluation_v2` شوید. از CMD دستور `py -0p` را اجرا کنید و مطمئن شوید Python 3.12 نسخه 64 بیتی نصب است.
3. روی `install_offline.bat` دوبار کلیک کنید. نصب فقط از پوشه محلی `wheelhouse` انجام می‌شود و اینترنت نمی‌خواهد. این مرحله محیط مجازی `.venv` را می‌سازد و وابستگی‌ها را نصب و بررسی می‌کند.
4. وقتی پیام موفقیت دیدید، `run_windows.bat` را دوبار کلیک کنید. پنجره را باز نگه دارید.
5. روی خود سرور مرورگر را باز کنید و به `http://127.0.0.1:5000` بروید.
6. برای اطمینان از سلامت API، `http://127.0.0.1:5000/api/health` را باز کنید؛ پاسخ باید با `"ok": true` شروع شود.

## بخش C — استفاده در شبکه داخلی سازمان

برنامه با Waitress اجرا می‌شود و روی پورت TCP `5000` به رابط شبکه گوش می‌دهد. ابتدا با دسترسی محلی وارد سامانه شوید و رمز مدیر و رمز تمام ارزیاب‌ها را از قسمت مدیریت کاربران تغییر دهید. رمزهای اولیه عبارت‌اند از مدیر `admin / admin123` و ارزیاب‌ها `evaluator1` تا `evaluator7` با رمز `eval123`.

بعد از عوض کردن رمزها:

1. روی سرور `ipconfig` را اجرا کنید و مقدار IPv4 مربوط به کارت شبکه سازمان را یادداشت کنید.
2. اگر اجازه Administrator دارید، `allow_firewall_port.bat` را با راست‌کلیک و `Run as administrator` اجرا کنید. این فایل یک قانون ورودی TCP 5000 برای پروفایل‌های Domain و Private ایجاد می‌کند. اگر اجازه ندارید یا سیاست‌های سازمان اجازه نمی‌دهد، باید مدیر شبکه قانون مناسب را اضافه کند.
3. از رایانه دیگری در همان شبکه، `http://IP-سرور:5000` را باز کنید؛ به‌جای `IP-سرور` عدد IPv4 سرور را وارد کنید.

**سامانه را به اینترنت عمومی منتشر نکنید.** نسخه فعلی برای شبکه داخلی طراحی شده و به‌تنهایی HTTPS ارائه نمی‌کند. دسترسی شبکه و باز کردن پورت تابع سیاست‌های امنیتی سازمان است. اگر سیاست سازمان HTTPS یا سرویس خودکار هنگام روشن شدن را لازم می‌داند، باید آن بخش با ابزارهای مورد تأیید سازمان تنظیم شود.

## اجرای روزانه

- شروع: دوبار کلیک روی `run_windows.bat`
- توقف: در پنجره سرور `Ctrl+C`
- بررسی نصب: `verify_windows.bat`
- پشتیبان‌گیری: `backup_now.bat` یا `backup_db.py`؛ خروجی در پوشه `backups` قرار می‌گیرد.

## اطلاعات مهم و نگه‌داری داده

- پایگاه داده: `instance\evaluation.db`
- کلید نشست: `instance\.secret_key`
- بکاپ‌ها: `backups\`

این فایل‌ها را حذف یا در اختیار افراد غیرمجاز قرار ندهید. پیش از جایگزینی نسخه، بکاپ تهیه کنید. برای انتقال سامانه‌ای که داده واقعی دارد، پایگاه داده و کلید نشست باید جداگانه و امن جابه‌جا شوند؛ ZIP آماده‌سازی برای جلوگیری از انتقال تصادفی داده‌های واقعی، این فایل‌ها را در بسته نهایی قرار نمی‌دهد.

## عیب‌یابی

- `wheelhouse` پیدا نشد: بخش A کامل انجام نشده است؛ دوباره `prepare_offline_packages.bat` را اجرا کنید.
- Python 3.12 پیدا نشد: نصب 64 بیتی Python 3.12 یا مسیر `py -3.12` را بررسی کنید.
- آدرس روی خود سرور باز می‌شود ولی روی رایانه‌های دیگر نه: IP سرور، اتصال شبکه و قانون Firewall را بررسی کنید.
- خطای پورت در حال استفاده: اگر برنامه دیگری پورت 5000 را گرفته، مقدار `PORT` را قبل از اجرا مثلاً به `5001` تغییر دهید و همان پورت را در Firewall باز کنید.
- خطای پایگاه داده یا ذخیره: مطمئن شوید پوشه پروژه در مسیر محلی قابل‌نوشتن مانند `C:\OrgEvaluation\` است، نه `Program Files` و نه فقط روی فلش.
